# Generated Analysis Artifacts

Machine-readable analysis of the TSL6 **runtime** image, generated from the
stripped payload. Regenerate with:

```sh
python tools/gen_analysis.py      work/runtime.payload.bin analysis/
python tools/functions.py         work/runtime.payload.bin json analysis/functions.json
python tools/decode_telemetry.py  work/runtime.payload.bin json analysis/telemetry.json
python tools/gen_boot_analysis.py work/boot.payload.bin    analysis/boot.json
python tools/functions.py         work/boot.payload.bin    json analysis/boot_functions.json
```

All offsets are payload offsets (image base 0). See
[../FIRMWARE_INTERNALS.md](../FIRMWARE_INTERNALS.md) for the prose explanation
and evidence.

## Files

| File | Contents |
|---|---|
| `memory_map.json` | Linker constants (`gp`, `sp`), region model, startup facts. |
| `command_dispatch.json` | Every BLE command and its handler offset, with the comparison site and whether the match is by branch-taken (`beq`) or fall-through (`bne`). |
| `action_table.json` | All 253 action-dispatcher entries: stub offset, dispatch kind, shared worker, immediate arguments, catalog label, and reuse groups. |
| `rule_engine.json` | Shortcut/rule table structure (primary 256-byte table plus two secondary tables). |
| `functions.json` | Recovered function inventory and call graph (419 runtime functions): per-function start/extent/callees and a caller index. Generated by `tools/functions.py`. |
| `telemetry.json` | Dashboard `0xB0` packet field map: per field, the source getter address, bit width, shift, and correlated label. Generated by `tools/decode_telemetry.py`. |
| `boot.json` | Bootloader structure: startup constants, update-command dispatcher, and the flash erase/program/verify flow. Generated by `tools/gen_boot_analysis.py`. |
| `boot_functions.json` | Function inventory/call graph for the boot image (84 functions). |

## Caveats

- Catalog labels come from the live backend action catalog (`funlist.js`) and
  are **correlated**, not confirmed against vehicle-side behavior.
- Worker targets flagged `worker_resident` point above the downloadable image
  into the resident BLE-stack/bootloader region.
- These files describe the archived build only
  (`535C62E239E339E31475FB10`, runtime `V1.0.00`, boot `V1.2.00`).
